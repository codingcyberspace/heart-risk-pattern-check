Data & methodology

From dataset to decision surface.

STEP 01

Input

Each model starts from a defined feature vector. The lab exposes the relevant controls instead of hiding the inputs behind a single opaque button.

STEP 02

Transform

Model-specific preprocessing is applied locally — including standardization and categorical handling where the embedded model requires it.

STEP 03

Inference

Stored model parameters are applied in the browser to produce the model output. The interface then surfaces the result and supporting context.

STEP 04

Explain

Driver bars, probability distributions and evaluation views help make the output easier to inspect and discuss.

STEP 05

Evaluate

Evaluation is presented separately from inference so accuracy and other reported metrics are not confused with an individual prediction.

STEP 06

Extend

New problem statements can be added as registry entries, keeping the platform structure reusable as the club's model collection grows.
